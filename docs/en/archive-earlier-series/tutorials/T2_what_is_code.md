# T2: What is Code?

*"Code is instructions for computers, written in a language they understand"*

## The Language of Computers

Code is like writing a recipe, but instead of cooking food, we're telling a computer what to do. It's a special language that computers can understand and follow perfectly.

## Why We Need Code

### 1. Precision
Computers need very precise instructions. They can't guess what you mean.

### 2. Repetition
Computers can do the same thing millions of times without getting tired.

### 3. Speed
They can follow instructions incredibly fast.

## Writing Your First Code

Let's write some simple instructions:

```clojure
;; Tell the computer to say hello
(println "Hello, world!")

;; Tell it to do math
(+ 5 3) ; => 8

;; Tell it to remember something
(def my-favorite-color "blue")

;; Tell it to use what it remembers
(str "My favorite color is " my-favorite-color)
```

## The Building Blocks

Code is made of:
- **Numbers**: 1, 2, 3, 4.5
- **Words**: "hello", "world"
- **Instructions**: +, -, *, /
- **Names**: my-favorite-color

## Why This Matters

Learning to code teaches us:
- **Clear thinking**: How to break problems into steps
- **Precision**: How to be exact and specific
- **Creativity**: How to build new things from simple pieces

## The Path Forward

Code is the bridge between human ideas and computer actions. It's how we turn imagination into reality.

**From simple instructions to complex systems** - this is the way.
