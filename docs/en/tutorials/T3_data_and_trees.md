# T3: Data and Trees

*"Data is the foundation, trees are the structure"*

## What is Data?

Data is information that computers can understand and work with. It's like the ingredients in a recipe - numbers, words, and other information that we can use to build something.

## Types of Data

### Numbers
```clojure
42        ; A whole number
3.14      ; A decimal number
-5        ; A negative number
```

### Words and Text
```clojure
"hello"   ; A word
"Hello, world!"  ; A sentence
```

### Collections
```clojure
[1 2 3 4]        ; A list of numbers
["red" "blue" "green"]  ; A list of colors
```

## What are Trees?

Trees are a way to organize data, just like a family tree shows relationships between people. In programming, trees help us organize information in a clear, structured way.

## Why Trees Matter

Trees help us:
- **Organize**: Keep related information together
- **Search**: Find information quickly
- **Understand**: See relationships between pieces of data

## Building with Data

Just like LEGO blocks, we can combine simple data into complex structures:

```clojure
; Simple data
(def name "Alex")
(def age 25)
(def colors ["red" "blue" "green"])

; Complex data structure (a tree!)
(def person {:name name
             :age age
             :favorite-colors colors})
```

## The Path Forward

Understanding data and trees is like learning to read and write. Once you understand these basics, you can build anything!

**From simple data to complex systems** - this is the way.
