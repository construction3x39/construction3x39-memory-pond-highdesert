## AWS Account - Your Cloud Foundation ☁️🏗️

*"The wise find pleasure in water; the virtuous find pleasure in hills." - Confucius*

AWS (Amazon Web Services) provides the cloud infrastructure that powers much of the internet. The free tier gives you room to learn without cost.

### **AWS Setup Process**

1. **Go to aws.amazon.com**
2. **Create AWS Account**:
   - **Email**: Use your Gmail
   - **Account name**: "YourName Sacred Tech Learning"
   - **Account type**: Personal

3. **Contact Information**:
   - Use your real information (required for account verification)
   - Phone number will receive verification calls

4. **Payment Information**:
   - AWS requires a credit card even for free tier
   - Set up billing alerts at $1 to avoid surprises
   - Use the free tier calculator to understand limits

### **Essential AWS Security Setup**

**Immediately after account creation**:
1. **Enable MFA on root account**
2. **Create IAM user for daily use** (never use root for normal work)
3. **Set up billing alerts**
4. **Review free tier usage regularly**
