## First Power On - Meeting Your Mac 🔘🌸

**Step 1: The Welcome Dance**
- Press and hold the power button (top-right on MacBook Air)
- Watch for the Apple logo - this is your Mac's way of saying "Hello!"
- Be patient - first boot takes a few minutes as the system prepares itself

**Step 2: Choose Your Language and Region**
- Select your language (English for our tutorials)
- Choose your country/region
- Select your keyboard layout

**Step 3: Connect to the Internet**
- Choose your WiFi network
- Enter your password carefully - we'll store this securely soon
- Let the Mac download any immediate updates

## The Account Creation Ritual 👤🙏

*"Blessed are the pure in heart, for they will see God." - Gospel According to Jesus (Stephen Mitchell)*

**Creating Your Main Account**:
- **Full Name**: Use your real name (this helps our community recognize you)
- **Account Name**: Keep it simple - "firstname" or "firstnamelastname" 
- **Password**: We'll create a secure brain password system in the next lesson

**Privacy Settings** (Choose carefully):
- **Location Services**: On (needed for time zones and some learning apps)
- **Analytics**: Off (we keep our data private)

## Essential First Settings 🔧🌿

Under the guidance of Pushya nakshatra (the nourishing star), let's configure your Mac to support focused learning:

**System Preferences → General**:
- **Appearance**: Auto (switches between light/dark with the sun)
- **Accent Color**: Your choice - I love the sage green
- **Sidebar icon size**: Small (reduces visual clutter)

**System Preferences → Dock & Menu Bar**:
- **Size**: About 1/3 of the way (not too big, not too small)
- **Magnification**: Off (reduces distractions)
- **Position**: Bottom
- **Minimize windows using**: Scale effect (gentler than Genie)
- **Automatically hide and show**: On (maximizes screen space)

**System Preferences → Desktop & Screen Saver**:
- Choose a nature image that calms your spirit
- Set screen saver to start after 10 minutes (saves energy)

## The Sacred Software Installation 📱✨

*"The sage does not attempt anything very big, and thus achieves greatness." - Tao Te Ching (Stephen Mitchell)*

Let's install our essential tools in order of importance:

### **Essential Browsers & Communication**

**1. Brave Browser** (Our recommended secure browser):
- Go to brave.com in Safari
- Download and install
- Set as default browser when prompted
- We'll configure security settings in the next lesson

**2. 1Password** (Our password manager):
- Go to 1password.com
- Start free trial (we'll set up properly in the security lesson)
- Download and install the app
- Don't set up yet - we'll do this systematically

### **Development Tools** (We'll install these gradually)

**Homebrew** (The missing package manager):
- Open Terminal (press Cmd+Space, type "terminal", press Enter)
- Copy and paste this command:
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
- Press Enter and follow the prompts
- This might take 10-15 minutes - perfect time for tea and reflection

**Git** (Version control):
```bash
brew install git
```

**VS Code** (Our friendly code editor):
```bash
brew install --cask visual-studio-code
```

## Your First Terminal Blessing 🖥️🙏

## Daily Digital Hygiene 🧘‍♀️💻

*"When you realize there is nothing lacking, the whole world belongs to you." - Tao Te Ching (Stephen Mitchell)*

Set up these healthy practices from the beginning:

**Focus Mode**:
- System Preferences → Focus
- Create a "Learning" focus that silences everything except essential apps
- Schedule it for your study hours

**Night Shift**:
- System Preferences → Displays → Night Shift
- Turn on automatically from sunset to sunrise
- This helps your brain prepare for sleep

**Storage Awareness**:
- Apple Menu → About This Mac → Storage
- Keep at least 20% of your storage free for optimal performance
